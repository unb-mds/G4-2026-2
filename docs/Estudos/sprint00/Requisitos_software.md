# Estudos: Requisitos de Software

## Conceito: 
Em termos práticos, representam o contrato entre o problema (a dor do cliente/usuário) e a solução técnica (o software construído). são as condições, funções e restrições que um sistema deve cumprir para atender às necessidades do usuário e aos objetivos do negócio.

## Tipos de Requisitos
- Requisitos Funcionais (RF): Descrevem o que o sistema faz, como ações, entradas, saídas e regras de negócio (ex: permitir login, cadastrar clientes).
- Requisitos Não Funcionais (RNF): Descrevem como o sistema se comporta, definindo atributos de qualidade e restrições mensuráveis, como desempenho, segurança e usabilidade (ex: carregar uma tela em até 2 segundos).
- Requisitos de Usuário vs. Sistema: Os de usuário são de alto nível e mais abstratos; os de sistema são detalhados e servem de guia técnico para os desenvolvedores.

## Etapas da Engenharia de Requisitos
- Levantamento (Elicitação): Coleta de informações com os stakeholders por meio de entrevistas, questionários, protótipos ou observação.
- Análise e Documentação: Refinamento, remoção de ambiguidades e registro formal do que foi coletado.
- Validação e Verificação: Confirmação de que o documento atinge as expectativas reais e testes de viabilidade antes de iniciar a construção.
- Gerenciamento: Controle contínuo de mudanças para evitar que o escopo se perca ao longo do projeto.
